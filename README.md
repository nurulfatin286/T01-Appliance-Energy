# T01 - Appliance Energy Consumption Website

## About the Project

This project is a small interactive website developed for COS30045.

The website demonstrates the use of HTML, CSS and JavaScript to create an interactive website about appliance energy consumption in the Australian market.

## Website Pages

The website contains three main pages:

- Home
- Televisions
- About Us

The navigation menu allows users to switch between the pages using JavaScript.

The website also includes:

- Power logo navigation
- Mouse-over effects
- Current page feedback
- Responsive CSS styling
- Appliance energy consumption information
- Footer with project and GenAI acknowledgement

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Desktop
- Visual Studio Code

The purpose of this website is to provide a simple demonstration of appliance energy consumption in the Australian market.
